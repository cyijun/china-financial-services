# 行业可比公司分析

1. 冻结`as_of`、股票池、财务版本、预测期间、币种和复权口径。
2. 按真实业务暴露、价值链位置、客户、地区、规模、成长、利润率、资本结构和周期阶段选择同行，并记录纳入/排除理由。
3. 用`china-market-data`取得同日市值、估值和财务数据；当前行业成员不能回填历史。
4. 统一EV桥、净债务、少数股东、租赁、稀释股本、TTM/NTM和法定/扣非口径。
5. 亏损、负净资产或近零分母保持`N/M`；不使用0填充错误或缺失。
6. 报告原始分布、中位数、四分位、覆盖率和不可比项；异常先解释，不自动删除。
7. 对选样、期间和会计调整做敏感性；需要完整估值时调用`a-share-valuation-triangulation`。

输出原始数据来源、样本矩阵、口径调整、倍数/经营指标分布、异常解释、敏感性和缺口。只生成研究比较，不给交易或仓位动作。
