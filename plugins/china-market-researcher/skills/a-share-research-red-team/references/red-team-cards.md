# 红队挑战卡

## 失败路径卡

| 字段 | 要求 |
|---|---|
| 原结论 | 可证伪句子 |
| 失败路径 | 具体机制，不是泛泛风险词 |
| 类别 | 需求/供给/产能/财务/政策/治理/会计/技术/估值 |
| 当前支持证据 | 已有事实及来源 |
| 当前反证 | 与路径相反的事实 |
| 触发器 | 可观察、可记录、可注明时间 |
| 时间尺度 | 何时影响经济结果 |
| 区分证据 | 最能区分原解释与替代解释的数据 |
| 状态 | live/retired/unknown |

## 数据链挑战

- 是否把报告期当公告日？
- 是否用当前ST、行业或指数成员回填历史？
- 是否使用会被未来公司行动重算的前复权序列？
- 是否在Tushare失败后静默改用无PIT能力的AKShare接口？
- 是否把Mock或离线测试写成真实生产验证？

## 偏差卡

- 龙头、语言、叙事、确认、近因、幸存者和权威偏差。
- 概念标签是否对应真实收入、利润和现金流？
- 比较对象是否包含失败者和替代品？

## 结束条件

红队完成不意味着原结论错误。结束时指出最强反方是否被解决、结论需降级到何种强度、仍缺哪条最小证据。没有新增证据时，不因措辞更强改变事实判断。
