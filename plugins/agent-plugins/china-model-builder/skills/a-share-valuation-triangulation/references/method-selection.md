# 估值方法选择与检查

## 方法选择

| 公司类型 | 优先方法 | 主要注意事项 |
|---|---|---|
| 稳定经营、现金流可预测 | DCF+可比公司+历史区间 | 终值、资本强度、维持性资本开支 |
| 银行/保险/券商 | PB-ROE、剩余收益、DDM | 资本充足、准备金、负债成本和监管资本 |
| 周期资源品 | 中周期盈利、成本曲线、EV/EBITDA、PB | 禁止用峰值利润低PE判断便宜 |
| 多元集团 | SOTP | 分部口径、控股折价、少数股东和交叉持股 |
| 高成长但盈利较弱 | 情景DCF、单位经济、EV/收入辅助 | 区间更宽，退出倍数不替代经济逻辑 |
| 亏损且现金流不稳定 | 资产/现金跑道、情景分析 | 不强行给单点内在价值 |

## DCF最小检查

- 预测与历史驱动可桥接，FCF符号和口径一致。
- WACC组成有日期、来源和币种，现金流与折现率口径匹配。
- 终值用永续增长和退出倍数交叉检查，但不双重计入。
- 企业价值到股权价值桥包含适用的净债务、租赁、少数股东、非经营资产和稀释股本。
- 二维敏感性中心格等于基础情景结果。

## 可比公司最小检查

记录纳入/排除理由、业务相似度、规模、地区、增长、利润率、资本结构、会计准则、数据日期和预测期间。异常先解释口径和业务差异，不简单截尾。

## 展示原则

用区间和敏感性展示不确定性。只有用户明确提供且能解释决策权重时才加权；否则并列方法。
