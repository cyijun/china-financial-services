# A股财务与披露检查清单

## 数据准备

- 年报、半年报、季报、业绩快报/预告及全部更正公告。
- 审计报告、内控审计、问询函及回复、监管措施和会计差错说明。
- 至少八个季度与三至五个年度的三表、附注和主要经营KPI。
- Tushare财务行保留`ann_date`、`f_ann_date`、`end_date`、`report_type`和更新标志。

## 高价值检查

1. 累计经营现金流与净利润的长期差异及来源。
2. 应收、合同资产、票据和存货相对收入变化；先排除并购、汇率、季节性和组合变化。
3. 资本化研发、软件、利息或获客成本政策及资本化率变化。
4. 重复出现的“非经常”“重组”“转型”项目及扣非口径变化。
5. 商誉、长期股权投资、在建工程、预付款和其他应收款的减值与交易对手。
6. 分部重组、收入确认总额/净额变化、成本分类迁移。
7. 关联采购销售、资金占用、担保、控制人质押和少数股东损益异常。
8. 审计意见、关键审计事项、内控缺陷、审计师/CFO变动和问询函。

## 结论记录

每项写清原始数值、基准、口径、期间、来源、正常解释、风险解释和最小判别证据。禁止只列红旗而不提出验证路径。
