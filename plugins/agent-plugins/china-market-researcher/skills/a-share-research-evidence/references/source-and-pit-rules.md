# 来源与point-in-time规则

## 来源层级

1. 交易所、巨潮资讯、证监会及其他法定披露原文。
2. 公司年报、季报、临时公告、招股书、审计报告和业绩说明会记录。
3. 可追溯到原始文档的数据供应商；本项目结构化主源为Tushare。
4. 券商研报、行业协会、专业数据库和专家访谈。
5. 新闻、搜索摘要、社区和社交媒体，只作线索或情绪证据。

公司材料对事实披露权重较高，但其前景和因果解释仍需外部交叉验证。

## A股时点

- 年报、季报、快报和预告按实际披露时刻进入证据集；报告期只描述经济期间。
- 同一报告的更正、补充和会计差错修订保留版本链。
- 季度利润表和现金流量表可能为年初至今累计，单季比较先转换并保留公式。
- ST、退市、停牌、涨跌停、指数成分和行业分类使用历史状态。
- 价格注明前复权、后复权或不复权；回测优先保存原始价和复权因子。
- 盘中和盘后公告必须区分市场是否已有合理反应时间。

## 最小证据记录

| 字段 | 含义 |
|---|---|
| `claim_id` | 稳定编号 |
| `claim` | 待支持事实或数字 |
| `source_type` | 原始披露、Tushare、AKShare、研报、新闻等 |
| `document` | 文档或接口及版本 |
| `published_at` | 实际披露时间与时区 |
| `period_end` | 数据报告期 |
| `retrieved_at` | 抓取时间 |
| `locator` | 页码、表名、段落或查询参数 |
| `caliber` | 单季/累计、合并/母公司、法定/调整后等 |
| `status` | verified、conflicted、unverified、unavailable |

## 冲突处理

先比定义，再比期间，再比范围，再比版本，最后比来源。只有确认同口径仍冲突才升级为待核问题，不把不同口径平均成“折中值”。
