# A股行业概览

## 工作流

1. 固定`as_of`、行业定义、地理范围、产业链边界、统计口径和股票池。
2. 先调用`a-share-research-evidence`；高影响政策、产能和市场规模回到官方/原始材料。
3. TAM采用供给、需求或收入法，写明分子、分母、币种、含税/不含税、出厂/终端、重复计算和数据期；不能验证时给范围。
4. 画价值链并标出利润池、议价关系、进口依赖、关键瓶颈、产能建设周期和替代路径。
5. 分析需求驱动、供给弹性、库存、价格、资本开支和利用率；区分结构增长与周期反弹。
6. 历史公司集合使用`china-market-data`的上市/退市与成员区间；当前板块快照不能回填历史。
7. 政策分析写出条文、实施时间、受影响环节、传导机制、替代解释和验证指标。
8. 输出基础、偏弱、偏强情景及可观察触发器，不赋精确概率。

## 输出

输出范围、规模、价值链、利润池、供需周期、竞争结构、政策、股票映射、情景、反证和数据缺口。股票映射必须披露相关收入/利润证据；不提供超配、低配、买卖或仓位动作。
