# 估值方法选择

| 公司类型 | 优先方法 | 主要边界 |
|---|---|---|
| 稳定现金流 | DCF、可比公司、历史区间 | 终值和资本强度 |
| 金融机构 | PB-ROE、剩余收益、DDM | 资本、准备金和负债成本 |
| 周期资源品 | 中周期盈利、成本曲线、EV/EBITDA、PB | 不用峰值利润低PE判断便宜 |
| 多元集团 | SOTP | 分部口径、少数股东和控股折价 |
| 盈利弱的高成长公司 | 情景DCF、单位经济、EV/收入辅助 | 区间更宽，退出倍数不是经济逻辑 |

任何方法都必须展示估值日、预测版本、输入来源、敏感性和当前价格隐含预期。没有依据时不加权。
